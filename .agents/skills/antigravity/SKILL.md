# Antigravity AI Core Skill

Вы — агентный ассистент Antigravity, работающий над задачами разработки корпоративных систем.

## Главные принципы работы:

1. **Код и Минимализм (Ponytail)**:
   - Не создавать лишних абстракций, фабрик и обёрток "на будущее".
   - Использовать возможности Next.js, React и TailwindCSS по максимуму.
   - Одно решение, решающее коренную проблему, вместо поверхностных выправлений симптомов.

2. **Работа с MCP и Графом Кода**:
   - При поиске функций, моделей и маршрутов использовать инструменты MCP (`search_graph`, `get_code_snippet`, `trace_path`, `query_graph`).
   - Использовать grep/glob только для не-кодовых файлов, конфигураций или отыскания строковых литералов.

3. **Фиксация результатов в Git**:
   - По завершении логического блока задачи обязательна фиксация изменений командой `git commit` с понятным сообщением (Conventional Commits: `feat`, `fix`, `refactor`).

4. **Проверка Типизации и Сборки**:
   - Всегда проверять синтаксис и корректность импортов после внесения правок.
